# Яндекс.Вебмастер для lootz.ru

Подтверждение сайта и индексация через [Яндекс.Вебмастер](https://webmaster.yandex.ru/).

## 1. Добавить сайт

1. Откройте https://webmaster.yandex.ru/
2. **Добавить сайт** → `https://www.lootz.ru` (зеркало без www уже редиректит сюда)
3. Выберите способ **Метатег**

## 2. Код подтверждения

Вебмастер покажет что-то вроде:

```html
<meta name="yandex-verification" content="____________________" />
```

Скопируйте только значение `content` (строка из букв/цифр).

## 3. Railway → frontend → Variables

```
YANDEX_VERIFICATION=ваш_код_из_вебмастера
```

**Redeploy** frontend (пересборка образа не обязательна — мета вставляется при старте `server.js`).

Проверка: откройте исходный код главной (`View Source`) — в `<head>` должен быть:

```html
<meta name="yandex-verification" content="ваш_код_из_вебмастера" />
```

Затем в Вебмастере нажмите **Проверить**.

На backend задайте:

```
FRONTEND_URL=https://www.lootz.ru
```

От этого зависят URL в sitemap (не Railway-хост).

## 4. Sitemap

После подтверждения:

1. Вебмастер → **Индексирование** → **Файлы Sitemap**
2. Добавьте:

```
https://www.lootz.ru/api/sitemap.xml
```

Проверка вручную: в браузере индекс должен ссылаться на
`https://www.lootz.ru/api/sitemap-static.xml` и т.д. — **не** на `*.up.railway.app`.

Это индекс sitemap: статические страницы, посадочные `/apps` и `/games`, лоты и продавцы.

## 5. «Страница неизвестна роботу»

Для нового сайта это нормально, пока робот не обошёл URL. Ускорить:

1. Добавьте sitemap (шаг 4) и дождитесь статуса «OK» в Вебмастере
2. **Индексирование** → **Переобход страниц** → добавьте `https://www.lootz.ru/`
3. Если есть Яндекс.Метрика — включите **обход по счётчику** (Вебмастер → Индексирование → Обход по счётчику)
4. Убедитесь, что главное зеркало — `https://www.lootz.ru`

Индексация не мгновенная: после исправления sitemap и запроса переобхода обычно нужно подождать несколько дней.

## 6. Главное зеркало

В Вебмастере укажите предпочитаемое зеркало `www.lootz.ru` — то же, что в `FRONTEND_URL` на backend.
