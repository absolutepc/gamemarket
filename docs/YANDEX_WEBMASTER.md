# Яндекс.Вебмастер для lootz.ru

Подтверждение сайта и индексация через [Яндекс.Вебмастер](https://webmaster.yandex.ru/).

## 1. Добавить сайт

1. Откройте https://webmaster.yandex.ru/
2. **Добавить сайт** → `https://www.lootz.ru` (и при необходимости отдельно `https://lootz.ru`)
3. Выберите способ **Метатег**

## 2. Код подтверждения

Вебмастер покажет что-то вроде:

```html
<meta name="yandex-verification" content="____________________" />
```

Скопируйте только значение `content` (строка из букв/цифр).

## 3. Railway → frontend → Variables

```
YANDEX_VERIFICATION=ваш_код_из_вебмастера
```

**Redeploy** frontend (пересборка образа не обязательна — мета вставляется при старте `server.js`).

Проверка: откройте исходный код главной (`View Source`) — в `<head>` должен быть:

```html
<meta name="yandex-verification" content="ваш_код_из_вебмастера" />
```

Затем в Вебмастере нажмите **Проверить**.

## 4. Sitemap

После подтверждения:

1. Вебмастер → **Индексирование** → **Файлы Sitemap**
2. Добавьте:

```
https://www.lootz.ru/api/sitemap.xml
```

(если основной домен без www — `https://lootz.ru/api/sitemap.xml`)

Это индекс sitemap: статические страницы, посадочные `/apps` и `/games`, лоты и продавцы.

## 5. Главное зеркало

В Вебмастере укажите предпочитаемое зеркало (`www` или без) — то же, что в `FRONTEND_URL` на backend, чтобы не плодить дубли.
